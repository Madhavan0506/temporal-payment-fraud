Model comparison

All three models used the same supervised training period. The baseline used payment amount and time. The graph model added recent transfer counts, distinct counterparties and pair history. The hybrid model also used an Isolation Forest anomaly score.

Leakage checks and scope

  • Recomputing features on an earlier prefix reproduced those rows from the full history.
  • Removing simulator labels and audit identifiers preserved the model inputs.
  • Every model stayed within the validation false-positive budget before the holdout comparison.

The simulator includes legitimate group collections and payouts alongside coordinated fraud. These numbers describe this generated population. Estimating performance on an operating payment system requires independently labeled transactions from that system.
